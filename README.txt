STUTI JAIN PORTFOLIO
====================

FILES
- index.html : page structure and your portfolio content
- style.css  : purple-accent design, responsive layout and themes
- script.js  : theme toggle, mobile menu and scroll animations

RUN IN VS CODE
1. Extract this ZIP into a folder named stuti-portfolio.
2. Open VS Code > File > Open Folder > select that folder.
3. Install the Live Server extension (Ritwick Dey).
4. Right-click index.html > Open with Live Server.

BEFORE PUBLISHING — EDIT THESE PLACEHOLDERS IN index.html
- GitHub and LinkedIn links (currently href="#")
- YOUR_EMAIL@example.com
- Project repository links
- Education study dates / expected graduation year
- Certification names and completion dates
- Training dates and any details you want to make more specific

The portfolio intentionally has no profile photo and no resume download.
The theme toggle switches between dark and light mode and remembers the visitor's choice.
Internet is needed for Google Fonts and Lucide icons CDN.
